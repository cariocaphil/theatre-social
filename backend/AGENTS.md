# Backend agent notes

Extends root [AGENTS.md](../AGENTS.md). Open when working under `backend/`.

## Layering

- Routes: validate (Pydantic) → call service → map domain errors to HTTP.
- Services: queries, ownership, transactions.
- Models: persistence only — no business logic.
- Schema changes: Alembic under `alembic/versions/`. Never `create_all` outside
  tests. Review autogenerated migrations by hand.

## Layout

`app/api/routes` · `schemas` · `services` · `models` · `db` · `core`

## Verify (from `backend/`)

Same checks as the CI backend job:

```bash
uv run ruff check .
uv run ruff format --check .
uv run alembic upgrade head   # needs Postgres at DATABASE_URL
uv run pytest
```

New migration: `uv run alembic revision --autogenerate -m "…"` then review before
upgrade. Recipes: README.
